# 🏗️ Калькулятор ЛСТК-профилей

> Подбор и расчёт лёгких стальных тонкостенных профилей (ПП, ПГС, ПЗ): развёртка, раскрой из рулона, процент отхода, вес погонного метра и цена с учётом отхода. То, что менеджеры раньше считали вручную в Excel — теперь в пару кликов.

## Зачем

При продаже и проектировании ЛСТК-конструкций нужно быстро понять: какая развёртка у профиля, сколько штук выходит из рулона, какой будет отход и итоговая цена за погонный метр. Раньше это считалось вручную в Excel — медленно и с риском ошибки. Калькулятор делает расчёт мгновенно и единообразно, прямо в браузере.

## Что считает

Для профилей **ПП**, **ПГС**, **ПЗ** по введённым размерам (высота стенки, ширина полок, отгибка, толщина металла) и цене за тонну:

- **развёртку** профиля (с учётом радиусов гиба и количества гибов);
- **раскрой из рулона** — сколько профилей выходит из стандартной ширины рулона;
- **процент отхода** и отход в мм;
- **вес погонного метра** (по удельному весу металла);
- **цену** за погонный метр — без отхода и с учётом отхода;
- карту отходов по сочетаниям размеров.

Поддерживаемые толщины: 1.0, 1.2, 1.5, 2.0, 2.5, 3.0 мм (с соответствующими радиусами гиба и шириной рулона).

## Технологии

React · TypeScript · Vite · Tailwind CSS · React Hook Form + Zod (валидация) · Vitest · GitHub Actions

Расчётное ядро вынесено в `src/lib/calculator.ts` (чистые функции) и покрыто тестами `src/lib/calculator.test.ts`.

## Локальный запуск

```bash
npm install
npm run dev        # разработка
npm test           # тесты
npm run build      # production build
```

Тесты проверяют расчёт развёртки, раскроя, отхода, веса и цены, обработку недопустимых параметров и инварианты по всем типам профилей. Запускаются в CI на каждый push.
