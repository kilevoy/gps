# 🏗️ Единый калькулятор ЛСТК — ГОСТ + LGS-2

Калькулятор объединяет нормативный режим и реальные производственные возможности линии LGS-2.

## Расчётная модель

Для одного и того же профиля одновременно рассчитываются:

- **теоретическая развёртка** — инженерная геометрия по нейтральной линии;
- **ширина заготовки LGS-2** — технологическая развёртка по проверенной производственной формуле GPS;
- **теоретическая масса** — по номинальной толщине и плотности стали 7850 кг/м³;
- **производственная масса** — по фактическим многолетним удельным весам металла из GPS / 1С.

Раскрой рулона, отход, производственная масса и цена считаются по технологической ширине заготовки.

## Режимы

### ГОСТ

Проверка выполняется по перенесённому из калькулятора LSTK набору данных **«ГОСТ Р 58384 ∩ LGS-2»** для ПП, ПГС и ПZ. Это рабочая область пересечения нормативного сортамента с возможностями линии, а не декларация полного сортамента ГОСТ.

### LGS-2

Проверяются реальные ограничения оборудования:

- H: 100–350 мм;
- A/B: 40–100 мм;
- для Z полка B: до 95 мм;
- C: 13–27 мм;
- технологическая полоса: 180–625 мм;
- t: 1,0–3,0 мм из поддерживаемого производственного набора.

## Материалы и рулоны

| t, мм | Производственный вес, кг/м² | Теоретический, кг/м² | Материнский рулон |
|---:|---:|---:|---:|
| 1,0 | 7,5056 | 7,8500 | 1250 мм |
| 1,2 | 9,2304 | 9,4200 | 1250 мм |
| 1,5 | 11,8520 | 11,7750 | 1250 мм |
| 2,0 | 15,67696 | 15,7000 | 1250 мм |
| 2,5 | 19,6200 | 19,6250 | 1250 мм |
| 3,0 | 23,5000 | 23,5500 | 1000 мм |

Производственные коэффициенты сохраняют логику GPS / 1С и не заменяются теоретической плотностью стали.

## Статусы

- `ГОСТ + LGS-2` — профиль входит в рабочую нормативную область и изготавливается линией;
- `ГОСТ / недоступен LGS-2` — нормативный профиль вне технологической доступности линии;
- `Нестандарт LGS-2` — профиль не входит в рабочую нормативную область, но линия его изготовит;
- `Недоступен` — нарушены ограничения оборудования.

## Код

- `src/lib/gostRules.ts` — рабочие диапазоны ГОСТ Р 58384 ∩ LGS-2;
- `src/lib/unifiedCalculator.ts` — единое расчётное ядро;
- `src/lib/unifiedCalculator.test.ts` — regression-тесты производственной математики;
- `src/UnifiedApp.tsx` — новый интерфейс с переключателем ГОСТ / LGS-2 и двумя развёртками / двумя массами.
